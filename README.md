# Privacy Policy - Chatwork 一括招待

Chrome 拡張機能「Chatwork 一括招待」のプライバシーポリシーを GitHub Pages で公開するリポジトリ。

## 公開 URL（GitHub Pages 有効化後）

```
https://kumakuma-libe.github.io/privacy-policy-chatwork-bulk-invite/
```

## GitHub Pages 有効化手順

1. GitHub の本リポジトリ → **Settings** → **Pages**
2. **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` / Folder: `/ (root)`
3. **Save**
4. 数十秒待つと上記 URL でアクセス可能になる
