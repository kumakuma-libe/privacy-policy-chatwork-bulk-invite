プライバシーポリシー

最終更新日: 2026年5月24日（退室取消・元ロール記録対応）

本プライバシーポリシーは、Chrome 拡張機能「Chatwork 一括招待」（以下「本拡張機能」）における ユーザーデータの取り扱いについて説明します。

要点：本拡張機能は、ユーザーが入力した Chatwork API トークン、 および Chatwork API から取得したチャット情報・メンバー情報を、 すべてユーザーのブラウザ内（chrome.storage.local）のみに保存します。 本拡張機能の開発者・運営者を含む第三者への送信は一切行いません。

1. 収集・処理するデータ

本拡張機能が扱うデータは以下のみです。

  • Chatwork API トークン: ユーザーが設定画面で入力する Chatwork の API トークン
  • チャット情報: Chatwork API から取得するチャットルームの一覧・名前・最終更新日時・メッセージ数等
  • メンバー情報: ユーザーが管理者であるチャットの参加メンバーの表示名と Chatwork アカウント ID
  • チャットセット: ユーザーが作成した「セット」（チャットの ID とユーザー命名のグループ名）
  • 招待実行履歴: 一括追加操作の日時・対象数・成功失敗数（個人を特定できる情報は含みません・最大500件）
  • 退室取消（復元）履歴: 一括退室操作の対象メンバー名・対象チャット ID・退室前の元ロール（admin / member / readonly）（退室の取り消し＝元のロールでチャットへ再追加するため一時的に保存・最大5件のみ・ユーザー操作でいつでも削除可能）

2. データの使用目的

収集したデータは、本拡張機能の機能提供のみに使用します。

  • API トークンは Chatwork API への認証にのみ使用
  • チャット情報・メンバー情報は、ユーザーが追加先・追加対象を選択する画面の表示にのみ使用
  • チャットセットは、ユーザーが繰り返し同じ一括追加操作を行うための保存設定
  • 招待実行履歴は、ユーザーが過去の操作を振り返るためのローカル参照のみ
  • 退室取消（復元）履歴は、退室操作の取り消し（元のロールでチャットへ再追加）のためのみに使用

3. 第三者へのデータ送信

以下の場合に限り、ユーザーデータが外部サービスへ送信されます。

  • Chatwork API への通信: ユーザーの操作に応じて、Chatwork API（api.chatwork.com）へ API トークンとリクエストデータを送信します。送信データは Chatwork のプライバシーポリシー に従って処理されます。
  • 上記以外の第三者（本拡張機能の開発者を含む）へのデータ送信は一切ありません。
  • Google アカウント同期にも乗りません（chrome.storage.sync は使用していません）。

4. データの保存期間

  • API トークン・チャットセットは、ユーザーが拡張機能の設定画面または管理画面から削除するまで保存されます。
  • 招待実行履歴は最大 500 件まで保存され、それを超えると古いものから自動的に削除されます。
  • 退室取消（復元）履歴は最大 5 件のみ保存され、6 件目以降は古いものから自動的に削除されます。また、ユーザーは管理画面の「削除」ボタンでいつでも全件削除できます。元ロール情報（admin/member/readonly）も同じく最大 5 件のみ保存されます。
  • ユーザーが拡張機能を Chrome からアンインストールすると、上記すべてのデータは完全に削除されます。
  • 外部サーバーへの恒久的な保存は一切行いません。

5. データの販売・共有

本拡張機能は、ユーザーデータを第三者へ販売・貸与・共有することは一切ありません。

6. アクセス権限

本拡張機能は以下の権限を使用しますが、いずれも本拡張機能の機能提供のみに使用します。

  • storage: API トークン・チャットセット・実行履歴をブラウザ内に保存するため
  • sidePanel: Chrome サイドパネルに UI を表示するため
  • host_permissions: api.chatwork.com: Chatwork API への通信のため

これら以外のウェブサイト・データへのアクセスは行いません。

7. セキュリティ対策

  • API トークンは、ローカル保存のみ（chrome.storage.local）で、ネットワーク同期しません
  • 招待実行履歴には、操作の件数のみを記録し、Chatwork アカウント ID やメッセージ内容は保存しません
  • 退室取消（復元）履歴は元のロールでチャットへ再追加するため、アカウント ID・対象チャット ID・元ロール（admin/member/readonly）を含みますが、最大 5 件のみ・ローカル限定・ユーザーが随時削除可能です
  • ログ出力（console）にも API トークン・個人名・アカウント ID を出力しません
  • Chatwork API への通信は HTTPS で行います
  • 退室操作には 2 段階の確認ダイアログを設け、誤操作を防止します
  • 退室操作で対象チャットの管理者が 0 人になる場合は API レベルで操作を中止します

8. ユーザーの権利

ユーザーは以下の権利を持ちます。

  • 設定画面から API トークンをいつでも変更・削除できます
  • 管理画面からチャットセット・招待実行履歴・退室取消（復元）履歴をいつでも削除できます
  • Chrome の拡張機能管理画面から本拡張機能をアンインストールすることで、保存されている全データを削除できます

本プライバシーポリシーは予告なく変更される場合があります。重要な変更がある場合は、本ページにて通知します。
